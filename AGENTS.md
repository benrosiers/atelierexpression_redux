# Instructions du projet

Travail sur la branche main uniquement.

Inspecter, modifier, valider, puis committer.

Ne jamais incorporer :
- fichiers .env
- secrets
- node_modules
- dist
- donnees privees des participants

Preserver l'identite Atelier Expression.

Les fonctionnalites externes non configurees doivent afficher
un etat indisponible explicite.

Le site public et le service de reservation sont deux
systemes distincts.
