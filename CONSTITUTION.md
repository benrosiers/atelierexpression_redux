# Constitution

1. La communaute precede le commerce.
2. Respecter l'identite visuelle du site original.
3. Aucun faux evenement, temoignage ou participant.
4. Aucune confirmation fictive de reservation.
5. Aucune cle privee dans le navigateur.
6. Les inscriptions doivent respecter les capacites.
7. Les informations des participants restent privees.
8. Les changements sont valides avant publication.
9. Ne jamais ecraser le projet original.
10. Le paiement des activites se fait sur place.
