# Implementation Redux

## Base

Sources reprises de benrosiers/atelierexpression.

Astro reste responsable du site public.

## Calendrier

La nouvelle page /calendrier lit public/activites.json.

Ce fichier commence vide parce qu'aucune nouvelle activite
n'a ete confirmee pour le Redux.

## Reservations

Ne pas activer les anciennes integrations par supposition.

Les reservations necessitent un backend valide, un controle
atomique des capacites et une protection des donnees.

Aucune inscription reelle n'est declaree fonctionnelle
avant les tests de bout en bout.

## Publication

GitHub Pages est configure avec un workflow manuel.

Verifier le domaine, le contenu et les services externes
avant d'autoriser le deploiement public.
